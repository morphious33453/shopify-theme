# 🔥 QUICK FIX - Stop the Errors Now

## The Problem
Nuxt cached old file locations and won't let go.

## The Solution (Copy/Paste This)

**Stop your dev server** (Ctrl+C), then run these commands **exactly**:

```bash
# 1. Make sure you're in the project directory
cd ~/Documents/DEV-DADA/shopify-theme

# 2. Stop ALL node processes
killall node 2>/dev/null || true

# 3. Pull latest code
git pull origin claude/vue-storefront-updates-011CV4rNztJXHrY2kae4iono

# 4. NUCLEAR OPTION - Delete everything that could cache
rm -rf .nuxt
rm -rf node_modules/.cache
rm -rf dist
rm -rf node_modules/.vite

# 5. Reinstall (in case something broke)
yarn install

# 6. Start fresh
yarn dev
```

## If That STILL Doesn't Work

Try this more aggressive approach:

```bash
# Stop server
killall node 2>/dev/null || true

# Delete node_modules completely and reinstall
rm -rf node_modules

rm -rf dist
rm -rf yarn.lock

# Start
yarn dev
```

## Why This Keeps Happening

The `.nuxt/router.js` file is generated by Nuxt and caches file paths. When we renamed:
- `pages/Home.vue` → `pages/index.vue`
- `pages/Category.vue` → `pages/c/_slug_1.vue`
- `pages/Product.vue` → `pages/p/_slug.vue`

Nuxt needs to regenerate the router, but it's holding onto the old cache.
